## 🏥 Overview

**Doctello** is a innovative medical website designed to bridge the gap between healthcare providers and patients. The platform enables hospitals to manage patient data, helps patients find and consult with doctors, and provides disease classification and diagnosis assistance.

## 🚀 Getting Started

### Prerequisites
```bash
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Code editor (VS Code recommended)
- Git for version control
- Node.js (for local development server)
```

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/MAL-WD/Doctello.git
cd Doctello
```

2. **Install dependencies** (if using Node.js)
```bash
npm install
```

3. **Start development server**
```bash
npm start
# Server runs on http://localhost:3000
```

4. **Open in browser**
```
Navigate to http://localhost:3000
```
